# ML Service Platform

## 🎯 Назначение
Платформа для асинхронного выполнения ML задач с системой биллинга.
Пользователи могут отправлять данные на предсказание, а система обрабатывает их в очереди с помощью нескольких воркеров

## Функциональность
- Регистрация и авторизация пользователей
- Пополнение баланса (кредитная система)
- Выполнение ML предсказаний
- История транзакций и предсказаний
- Валидация входных данных
- Администраторская панель

## 🏗 Архитектура
- **FastAPI** - REST API для пользователей
- **PostgreSQL** - хранение пользователей, баланса, истории
- **RabbitMQ** - очередь задач
- **3 ML воркера** - асинхронная обработка

## 🔄 Бизнес-процесс
1. Пользователь пополняет баланс
2. Отправляет данные на предсказание
3. Система ставит задачу в очередь
4. Воркер обрабатывает задачу
5. С баланса списываются кредиты
6. Результат доступен по API

## 🧠 ML модели
В демо-версии используются предобученные модели scikit-learn:
- **Классификатор** (RandomForest)
- **Регрессор** (LinearRegression)  
- **Кластеризация** (KMeans)

## 📈 Масштабирование
- Горизонтальное масштабирование за счет увеличения числа воркеров
- Балансировка нагрузки через RabbitMQ (round-robin)
- Контейнеризация Docker для легкого развертывания
